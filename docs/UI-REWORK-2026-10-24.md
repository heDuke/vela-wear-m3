## 本轮实现

2026-10-24 追加调整：band10、band9 顶部返回按钮水平居中；Stepper、数值位置与分页演示同样居中，标题独立排在按钮下方，Stepper 内容高度同步扣除导航区。round 与 Pro 导航保持原布局。

- 圆屏普通页面只保留居中标题，Stepper 使用全屏 35% / 30% / 35% 结构、8dp 间隔和 5.2% 屏高的上下边距。取消后抬手不会重播反馈，支持长按重复、边界与禁用。
- 实际按钮接入反馈。IconButton 和完整 Button 保留可选形变；CompactButton 保持 32dp 可见区、48dp 触控区，额外形变标为适配。播放／暂停使用同一图标体系的适配过渡。
- SwitchButton 以选择器切换四种图标组合，每组有开、关、禁用开、禁用关。两种 API 共用 32×24dp 图形，轨道实际高 22dp；禁用轨道、滑块和图标分别着色，反向从当前状态继续。
- LevelIndicator 采用 72° / 6dp、SecondaryDim / SurfaceContainer，按实际路径包围盒裁切；独立于列表滚动，并单独生成禁用图形。
- 2026-10-24 Stepper 追加：所有设备去掉返回头部，按 androidx Stepper 全屏布局；LevelIndicator 改为 ScrollIndicator.kt 的屏宽圆弧（3dp 移动间隙、近端点圆点），tween 500ms 从当前位置重启；按压改为底色 #4D3D76→#5D4D84 + 12600/260 形状弹簧；长按 60ms 连发；禁用标签同样变灰。
- 分页移植参考窗口与收敛计算，包含六个可见点、背景弧和选中弧段。内容与指示器随拖动同步，阈值为 25%，首末夹紧，区域内右滑不返回。
- Arc TimeText 使用模拟器 MiSansW 的真实 advances、ascent / descent 和字形 PNG，顶部与示例共用排版。先保留完整时间，再截短状态；状态移除时一起移除分隔符。Pro 顶部直排，round / band 顶部 Arc。
- Slider 采用 12dp 选中条、4dp 未选中条、2dp 分隔点，包含连续、分段及变色。band 的轨道、数值和 48dp 增减键纵向重排。
- 进度含普通、小尺寸、大尺寸、不确定、连续／独立分段、官方弧形加载、8／12dp 线性、溢出和适配确定弧形。官方 Arc 默认范围是底部 65°–115°；head / tail 延迟 0 / 300ms、各运行 600ms，周期 2 秒。
- Confirmation 将圆形、拉伸容器、对勾、文字分阶段挂载，默认 4 秒；执行代次阻止关闭、重入或隐藏后旧回调重新创建动画。
- band 九页采用单列、短中文主标签和独立说明；卡片元信息分行，时间 HH / MM 上下排列，选择器保留全部变体。

## 性能与兼容范围

滚动仅保存最新位置，TLC 和 ScrollIndicator 共用 33ms 调度器；只计算可见项及前后各一项。曲线在生成阶段采样，缓存样式并跳过重复提交。隐藏时停止计时器和播放器、恢复按压外观。普通时间对齐分钟边界更新；时间演示仅可见时按秒更新。

不确定圆环保留 5 秒周期，旋转交给原生 transform，帧序列只描述弧长及轨道间隙。弧长量化的端点位移上限为 0.9 个物理像素；这是几何采样上限，不代表已通过原生栅格误差验收。专用帧资源的减少幅度见最终统计。

API 1 不使用 image-animator；可选形变采用端点降级，对勾淡入。API 2 使用局部图形与原生播放器；交互形变通过一个共享状态机采样，保留当前位置与速度。API 2 原生性能仍需可用镜像验证。

## 验证与限制

自动验证覆盖四设备 × 两种 API 的语法、资源、生命周期、按钮取消／重入、开关反向／禁用、Stepper 长按／边界、分页首末／回弹和确认层关闭竞态。当前 6,038 项断言通过；不代表 6,038 个独立视觉用例。

Chrome 设计预览、图形关键帧与模拟器实拍分开存放。Pro、band9 提供设计预览和构建／状态检查，没有宣称有原生实拍。

隔离 pre4 模拟器能启动 API 1 包，但振动接口会触发 libuv async.c:212 断言并重启，基线和新包均复现。原生交互与性能采用仅关闭振动的 release 测量副本，正式 RPK 保留振动功能；此条件不能视为完整原生验收。API 2 的 watch5 镜像存在文件系统挂载问题，其原生动画、真机表现和原生进度替代方案的“≤1px 且性能不回退”判定仍阻塞，正式实现保留局部 PNG。

30fps、超过 100ms 的可见停顿减半、JS p95 降低 30% 和每包不超过本轮基线的目标，必须按最终数据判断，不能由主机 VM 或 Chrome 推断。

最终原生验证还出现资源读取 ENOENT 与 adb 传输 EOF，不能保证安装完整，故中间原生图片仅保留在 diagnostics/，最终三轮 A/B 性能验证标记为阻塞。API 1 官方弧形加载采用固定活动弧段与透明度反馈；完整差异和未达标项见[最终验收记录](UI-ACCEPTANCE-2026-10-24.md)。
