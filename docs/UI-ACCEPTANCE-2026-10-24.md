## 原生验证阻塞

隔离 pre4 模拟器可启动 API 1 界面，但基线和新包均会因振动接口触发 libuv async.c:212 断言重启。诊断时使用仅关闭振动的测量副本；正式安装包保留原功能。随后出现图形文件 ENOENT 和 adb 批量传输 EOF，无法保证最终安装目录完整。因此中间截图与基线录屏仅作为故障诊断，不作为最终版本视觉或性能验收证据。

API 2 watch5 镜像存在文件系统挂载错误，未形成可靠运行环境。Pro、band9 仅完成构建、状态检查与设计预览。没有四设备最终原生实拍，也没有可信的三轮 release A/B 性能结论。30fps、超过 100ms 的停顿减少 50%、原生 JS p95 降低 30% 均标记为阻塞；物理返回键的模拟器映射尚未验证。

## 兼容与设计差异

- API 1：形变采用端点降级，对勾淡入；官方弧形加载使用固定活动弧段与透明度反馈，不能连续复现 API 2 路径变化。
- API 2：局部帧与原生播放器补足图形变化；交互形变保留当前状态与速度，其设备播放表现仍待可用镜像确认。
- CompactButton 额外形变、播放／暂停过渡、局部确定弧形及 band Slider 排布、band SwitchButton 纵向堆叠（开关右对齐）均为项目适配变体；SwitchButton 只保留官方默认（滑块内始终有对勾）。
- Arc TimeText 当前按 OFL Noto Sans SC 实际字体度量生成字形（发布前替换原 SDK 字形），运行设备必须使用相同资源；与 Android 原字体仍存在字形差异。
- 原生进度替代方案尚未通过 ≤1 物理像素及性能不回退的联合验证，正式实现保留局部 PNG。
