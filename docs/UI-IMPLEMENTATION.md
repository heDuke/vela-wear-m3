# 2026-10-23 Wear M3 UI 实现记录

本轮按用户确认的 UI 计划调整 gallery，继续使用模板片段与纯函数；没有启动组件库重构。基准固定为 androidx 提交 `2f557dc1f1ec71edae73e2c16b0e446523c644b7`，来源保存在 [参考源码](ref/androidx-m3-src/)。

## 已接入的界面和交互

| 区域 | 当前实现 |
|---|---|
| 导航 | 顶部圆形箭头随列表滚动；右滑结束后返回；覆盖层、页面内演示、路由依次关闭 |
| 按钮 | Filled / Tonal / Outlined / Child、主副标签、三类 IconButton、Compact、禁用；默认固定形状与可选 Button / IconButton 形变分别演示 |
| 开关 | 官方两组：无／有行首图标，滑块内始终有对勾；每组开启、关闭、禁用开启、禁用关闭；band 纵向堆叠、开关右对齐为适配 |
| Stepper | 顶部增加、中部数值、底部减少，0–10 范围和独立禁用态；点击数值切换禁用，左右位置条不使用列表滚动状态 |
| 数值位置 | 独立 LevelIndicator 演示及 Stepper 联动；圆屏弧形，矩形与手环直条 |
| 分页 | 页内横向和纵向演示；3 / 8 页切换；最多显示六个点、边缘收敛；圆屏沿屏幕弧线排列 |
| 时间 | 手环 HH / MM 上下排列；直排和 Arc 分别展示纯时间、状态＋分隔符＋时间；窄屏 Arc 缩短状态 |
| 进度 | 确定、不确定、分段、局部弧形、线性；0 / 5 / 50 / 95 / 100 预置值和自动演示 |
| 成功确认 | 容器独立拉伸为倾斜胶囊、图标保持正向、文字延后出现；4 秒后关闭，退出清理动画 |
| 滚动位置 | 滑块按视口 / 内容比例计算并限制于 0.30–0.70；平滑映射位置，不可滚动时隐藏 |
| 多屏 | round、pro、band10、band9 分别生成尺寸、列排布、留白和图形资源，未对整页统一缩小 |

API 1 和 API 2 共用布局、状态与生成源。生成命令：

```powershell
node tools/gen.js band10 --animation basic
node tools/gen.js band10 --animation enhanced
npm run verify
npm run build:all
node tools/package-builds.js
```

`basic` 的 manifest 最低 API 为 1，`enhanced` 为 2。全量构建输出 16 个 RPK：四设备 × 两种 API × debug/release。压缩包和 SHA-256 清单保存在 `out/`；签名私钥仍只保存在忽略的 `sign/` 中。

## 动效与兼容差异

| 项目 | API 1 | API 2 | 尚存差异 |
|---|---|---|---|
| 不确定圆环 | 固定弧形 PNG 旋转 | 5 秒周期、150 帧局部动画 | 尚未通过模拟器与官方视频逐帧对照 |
| 确定进度 | 数值缓动，选择 PNG | 相同 | 图形按 5% 分档，有量化；完成态为终点图形，没有额外路径过渡 |
| Confirmation | 原生高度弹簧采样关键帧、图标淡入 | 容器同基础版；按官方 XML 路径描画对勾 | API 1 不描画；未验证设备上延迟、填充模式与重入的实际表现 |
| 对勾 | 静态 Material 图标 | 官方 `wear_m3c_check_animation.xml` 的变换路径、267ms，约 30fps | PNG8 与抗锯齿带来栅格差异 |
| 开关 | 位移、缩放和状态颜色 | 10 帧 / 300ms，图标、滑块尺寸和位移 | 禁用颜色当前采用透明度近似，轨道颜色帧间切换，不是完全连续混色 |
| 可选按钮形变 | 瞬时圆角状态 | 按下 3 帧 / 100ms，释放约 30fps / 600ms | 圆角插值仍为项目近似；快速重入从端点开始，非 Android 物理弹簧连续接续 |
| Stepper 按压 | 瞬时圆角状态 | 相同 | 没有独立的连续圆角帧动画 |
| 分页点 | 当前页高亮、首末边缘收敛 | 相同 | 不是完整复刻官方连续翻页插值 |
| 按钮默认反馈 | 透明度按压反馈 | 相同 | Vela 适配，不等同 Android ripple |

图形按设备生成、PNG8 量化，并将内容相同的帧引用到同一资源；生成器只拷贝被源码引用的资源。页面隐藏与销毁时清理计时器并停止 animator。新增 PNG 可通过 `npm run assets:ui` 重建；需要带 Pillow 的 Python，可用 `PYTHON` 环境变量指定路径。

## 验证边界

- 当前四设备 × 两种 API 的资源、语法、交互状态和生命周期检查共 3970 项断言通过。断言包含资源引用检查，并非 3970 个独立 UI 场景。
- [本轮设计预览](screenshots/ui-2026-10-23/previews/) 由实际生成的 UX 与页面状态在 Chrome 中转换渲染；不是 Vela 模拟器截图。最终对勾路径和时长校正后尚需刷新预览。
- 原模拟器截图仍保存在 [改前基线](screenshots/emulator/)，未覆盖。
- 本机 Vela 5.0 测试环境出现分区挂载错误与 ADB 掉线，未取得新 UI 的有效模拟器截图、录屏。四设备真机均未验收；手势互斥和动画性能仍需设备验证。
- 各包的大小、资源字节数、动画资源字节数、页面 JS 大小与编译告警写入 `out/size-report.json`。release 超过原 81KB 预算时明确标为未达标。
- 本轮尚未交付官方动画关键帧对照与短视频，不能据设计预览宣称全面还原或全部验收完成。
